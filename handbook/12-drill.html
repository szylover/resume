11. 面试拷打题库

WebRTC / Realtime
  1. WebRTC 为什么弱网更合适？哪些场景反而更差？
  2. ICE/STUN/TURN 的建连过程是什么？企业网络如何处理？
  3. Data Channel ordered/unordered、reliable/partial reliable 怎么选？
  4. speaker output level 阈值如何校准？静音、蓝牙和音量为零怎么办？
  5. FAR 到底从哪一层开始和结束？
  6. 用户打断时 client、service、model 谁是状态真源？
  7. server drain 时如何让 session 恢复而不重复 turn？
性能与冷启动
  1. 如何证明瓶颈是 SDK init 而不是 token 或 join？
  2. 为什么优化 P50 可能恶化 P99？
  3. 预热命中率只有 10% 时还值得吗？如何算成本？
  4. single-flight 如何处理调用者取消？
  5. 缓存 client 的 key 为什么包含 user/tenant/config/network epoch？
  6. 如何避免 warmup 和真实 join 同时创建两个 session？
  7. Feature rollout 的自动回滚阈值怎么定？
Kotlin / Coroutine
  1. coroutineScope 与 supervisorScope 在 warmup 中怎么选？
  2. Mutex 内 await 有何风险？如何避免长时间持锁？
  3. NonCancellable close 为什么只允许用于短清理？
  4. StateFlow 如何避免丢事件？一次性 effect 为什么不应放 StateFlow？
  5. 如何测试虚拟时间、timeout 和 race condition？
Compose Migration
  1. 为什么先迁 domain/state 再迁 UI？
  2. ComposeView 与 Fragment 生命周期如何绑定？
  3. SavedStateHandle 保存什么，不保存什么？
  4. 如何测 recomposition、jank、TTFD 与滚动性能？
  5. 双栈期间如何保证埋点语义一致？
行为与 Ownership
  1. 你做过最错误的技术判断是什么？
  2. 哪个 feature rollout 失败过？你如何止损？
  3. 与 service/iOS/host team 意见冲突时如何决策？
  4. 如果今天重做 WebRTC migration，你会先改什么？
  5. 哪些工作是你亲自编码，哪些是推动别人完成？
