12. 建议学习顺序

第 1 阶段：能讲

  1. 背熟三张图：transport、warmup、state machine
  2. 每个主项目录 2 分钟口述
  3. 补齐真实 ownership 和结果数据

第 2 阶段：能守

  1. 逐行解释 Kotlin 示例
  2. 回答所有 trade-off
  3. 准备 3 个 failure/incident 故事

第 3 阶段：能扩展

  1. 设计 server drain/resume
  2. 设计低端机预热预算
  3. 统一 WebSocket/WebRTC/GPT Live telemetry

你回来前要补的数据

  • Click-to-ready/FAR 前后 P50/P95
  • warmup hit/failure/no-audio
  • Compose 首屏/jank/重复请求
  • MeetApp latency/memory
  • BuildXL build/cache 改善

最终原则

简历只放高信号结果；这份手册保存完整技术深度。任何写了“主导、设计、解决”的 bullet，你必须能够画架构图、解释一个核心类、讲一个失败案例、给出指标定义，并说清为什么没有选择另一种方案。
