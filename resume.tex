\section{\faBriefcase\quad 工作经历}

\noindent
{\large\bfseries\color{darktext}\sffamily Microsoft} \hfill {\small\textcolor{accent}{SDE2 \quad|\quad 2017.06 -- 至今}}

\cventry{M365 Copilot Mobile Runtime — OCM}{2025 -- 至今}
{OCM Android SDK，服务于 OfficeMobile、Outlook、Teams 等宿主应用。}
\begin{itemize}
  \item \textbf{主导 Realtime Voice 从 WebSocket/SignalR 到 WebRTC 的 Android 迁移}：拆分 Media 与 Data/control plane，重构 shared voice state machine，移除旧 client buffering，支撑 Voice/Text/Vision 混合模态
  \item \textbf{主导 Voice 冷启动与连接性能治理}：拆解 click-to-ready 关键路径，实现 early connection、Warmup、SetupAndJoin 与 Data Channel reuse；显式建模 failed/stale/disconnected session，通过 single-flight、TTL 和 rebuild/rewarmup 避免重复初始化与坏连接复用
  \item \textbf{攻克首包、打断与网络恢复}：实现 Audio Burst、基于 speaker output level 的 Speaking/FAR 与 barge-in 状态机；补齐 ACS reconnect、DNS backoff，并重构连接阶段 telemetry 和错误分类
  \item \textbf{建设 Copilot Runtime 与合规基础设施}：设计 Selected Context 到 Sydney annotation 的 AI Context Pipeline、GPT-5/Model Switcher 与 Rich Response；完成合规 WebSocket 路由和 Compose 图片上传 Consent
\end{itemize}

\cventry{Outlook Android — Search 架构现代化}{2024 -- 2025}
{将 Java/View 体系的存量搜索模块渐进迁移到 Kotlin + Jetpack Compose。}
\begin{itemize}
  \item 主导 People/Files/Events 多 Tab 从 Java/View 到 Kotlin/Compose 的渐进迁移：先抽离领域状态与数据接口，再通过 ComposeView/互操作层替换 UI，保持旧宿主、导航和遥测协议兼容
  \item 设计单向数据流与可恢复 UI state，治理重复请求、Tab 切换状态丢失和列表重组；以 Feature Flag 双轨 rollout，对比冷启动、首屏渲染、滚动与错误率并保留快速回滚能力
\end{itemize}

\cventry{Teams MeetApp — AI 会议智能平台}{2022 -- 2024}
{Teams Windows Desktop React Native 项目，为 Teams Desktop 提供 AI 增强的会议管理体验。}
\begin{itemize}
  \item 从零设计 MeetApp 数据与导航架构：统一 Graph/Substrate API、Insight Builder 与 Calendar 数据管道，支撑 Upcoming/Recent/Missed 分类和 Recap 深链
  \item 设计 Copilot 入口与 CrossMeetingCatchUp，接入 BizChat streaming 对话流并利用 GPT-4 生成跨会议摘要
  \item 建立性能 telemetry 与毫秒级日志调试工具，结合 Kusto/Augloop 定位内存泄漏、导航延迟和用户切换等生产问题
\end{itemize}

\cventry{语音助手与对话式 AI（Cortana / PME）}{2019 -- 2022}
{Play My Email、Catch Me Up、Play My Messages 三个语音产品的 Android 端。}
\begin{itemize}
  \item 主导 Catch Me Up 在 Teams Android 从 POC 到 GA：设计 React Native 原生桥接，打通 KWS/AEC/TTS、消息 Like/Reply/Mark-as-Read 与宿主 SDK
  \item 实现 Outlook Play My Email 的 TTS Streaming、语音 triage 与 session 恢复，处理网络中断、播放状态和重试一致性
  \item 完成 Hermes 预编译 Bundle 与 SDX 架构迁移，支持 Gov Cloud 部署并降低运行时集成复杂度
\end{itemize}

\cventry{SharePoint Online — 大规模构建基础设施}{2017 -- 2019}
{SharePoint Online 大规模 Monorepo 构建系统现代化。}
